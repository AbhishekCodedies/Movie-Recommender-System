# 🎬 Movie Recommender System

A Content-Based Movie Recommendation System built using Python, NLP, Scikit-Learn and Streamlit.

## Features
- Movie Recommendations
- NLP Based Similarity
- CountVectorizer
- Cosine Similarity
- Streamlit UI

## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- NLTK
- Streamlit
