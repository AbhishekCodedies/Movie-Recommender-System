# 🎬 Movie Recommender System

A Content-Based Movie Recommendation System built using Python, Machine Learning, NLP, Scikit-Learn, and Streamlit.

## 📌 Features

* Recommend similar movies based on content
* Uses genres, keywords, cast, and director information
* NLP preprocessing and stemming
* CountVectorizer for text vectorization
* Cosine Similarity for recommendation
* Interactive Streamlit web application

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* NLTK
* Streamlit

## 📂 Dataset

TMDB 5000 Movie Dataset

* tmdb_5000_movies.csv
* tmdb_5000_credits.csv

## ⚙️ Project Workflow

1. Data Collection
2. Data Cleaning
3. Feature Extraction
4. NLP Preprocessing
5. Text Vectorization using CountVectorizer
6. Cosine Similarity Calculation
7. Movie Recommendation Generation
8. Streamlit Web App

## 🚀 How to Run

Install dependencies:

```bash
pip install pandas numpy scikit-learn streamlit nltk
```

Run the application:

```bash
streamlit run app.py
```
